# Contributing to Lake Lab

Keep this a static, small, privacy-preserving educational tool. Do not add tracking, accounts, keys, runtime external services, remote fonts or uploaded student data.

- Use short, grade-six explanations. Put educational content in `content/en/`, outside station components.
- Keep stations independent, configurable and keyboard operable. Offer tables/downloads with charts and distinguish measured, derived and simulated results.
- Every model coefficient needs a source or an explicit author-chosen label, units, assumptions and omissions.
- Every asset needs an author, licence, source, retrieval date and transformation record. Public access alone is not an open licence.
- Preserve measurement qualifiers, sample media, methods, units and source IDs. Do not interpolate missing samples into measured records or invent toxin labels.
- Keep filenames/links relative for GitHub Pages. Do not require a build step for the site.
- Run the validation and storage checks in README, then inspect desktop and phone layouts and keyboard paths. Explain which science still needs expert review.
- Submit your original code under MIT and original content under CC BY 4.0. Keep third-party notices intact. Avoid including names or other personal information from children in issues or examples.

Please describe the learning problem, the resulting behavior, supporting sources and checks performed. The team must develop its own FLL solution; prompts should invite inquiry rather than hand over a finished project.

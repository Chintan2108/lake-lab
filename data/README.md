# Frozen source library

The live app reads only local files. No source API is called at runtime.

`manifest.json` lists each collection, exact source requests, licence evidence,
retrieval time, observation scope, processing, limitations and downloadable-file
checksums. Every collection has its own README and metadata.json. Raw source
responses and request sidecars support rechecking the cleaning step.

The approved core environmental window is 2016–2025. The older shoreline and
2019/other-year image examples retain their own dates. An image is not a toxin
observation. Derived display geometry and illustrations are labelled separately.

Refresh is manual; see the repository README and scripts. Do not refresh during a
student session or silently replace missing values. Review changes before commit.
